# Zombie Card Survive - 遊戲概念

> **文件說明**：本文件由現有 GDD 與目前可玩原型反向整理而成，
> 記錄已核准的高層遊戲定位；詳細規則仍以來源 GDD 為準。

## 暫定名稱

**Zombie Card Survive**

## 一句話提案

一款 PC 優先的殭屍末日基地生存卡牌 Roguelite。玩家以基地指揮者的身分，
透過卡牌調度倖存者、物資、防衛力量與基地運作，在立即生存、風險探索與
長期建設之間做出取捨，設法讓基地存活至指定天數。

## 核心幻想

> 在物資逐漸耗盡、威脅持續滲入每一項計畫的末日中，
> 把每一手牌轉化為讓脆弱社群多活一天的命令。

玩家是倖存者基地的指揮者，而不是親自執行所有行動的單一倖存者。
卡牌代表命令、人員調度、物資來源、防衛準備與基地能力；探索則代表
派遣倖存者或小隊前往外部地區。施工、製作、食物計畫、戰鬥值與牌組整理，
共同表現玩家如何分配有限的人力、時間與材料。

## 玩家體驗

遊戲追求的是有壓力但可以規劃的決策，而不是只能被動承受隨機懲罰。
每一輪都應迫使玩家在下列選擇之間取捨：

- 解決眼前短缺，或投資未來穩定性。
- 維持牌組可靠度，或為了強力收益承擔污染。
- 立即消耗防衛力量，或保留能力應付更大的威脅。
- 派遣探索隊尋找稀缺機會，或保護已經脆弱的基地。

玩家應感覺良好規劃確實能延長生存，但基地永遠不會徹底脫離壓力。

## 設計支柱

### 1. 受限制的牌組規劃

牌組代表基地的有效運作能力，而不只是強力卡牌的集合。玩家必須在
5n 正規牌組、卡牌欄位、有限使用次數、替換規則與持續污染之間規劃，
決定基地每一輪能穩定完成哪些工作。

**設計判準：** 當牌組規則存在多種方案時，優先採用能形成有意義規劃限制，
同時不破壞正規回合節奏的方案。

### 2. 探索同時帶來希望與麻煩

探索是取得新卡牌、物資、地區與未來機會的主要來源，也會讓基地接觸
殭屍與其他風險。一次有價值的探索應擴大玩家的可能性，同時帶回一項
需要評估或承受的新問題。

**設計判準：** 當探索獎勵存在多種方案時，應讓明確收益伴隨可理解的風險，
避免提供完全沒有後果的升級。

### 3. 犧牲現在以建設未來

食物、資源、施工工作與製造力迫使玩家在度過當前壓力和強化未來基地之間
選擇。建築可以穩定壓力並解鎖新行動，但不應讓玩家永久免疫某個生存系統。

**設計判準：** 當成長獎勵存在多種方案時，優先提供可管理的壓力與新選項，
而不是讓一項生存問題永久失效。

## 核心遊戲循環

### 回合循環

1. 抽取正規卡牌並恢復本回合可用能量。
2. 打出卡牌下達命令，取得食物、資源、戰鬥值、規劃能力、探索機會或施工進度。
3. 抽到殭屍附加卡時自動揭露，並補回被占用的正規卡牌抽取。
4. 分配可用防衛力量並結束回合。

### 一輪循環

1. 以每回合五張正規卡的固定節奏循環正規牌組。
2. 輪末結算仍存在的殭屍威脅與基地生存壓力。
3. 在下一輪前處理事件、施工、製作、卡位空缺與合法替換。
4. 重建正規牌組並開始基地下一天的運作。

### 長期循環

1. 派遣探索隊，從危險度與預期收益不同的地區中選擇目的地。
2. 取得卡包、物資、藍圖、倖存者或其他機會，同時承擔殭屍污染風險。
3. 整合選定卡牌、建造或升級建築，並安排卡牌製作。
4. 調整牌組與基地，因應逐漸上升的生存壓力。
5. 存活至本局要求的天數。

## 代表性系統

- 維持固定五張抽牌與可預期輪長的 5n 正規牌組。
- 不佔正規容量、也不產生額外回合的殭屍附加卡。
- 卡牌類型欄位、等量替換、有限使用次數、耗盡與輪末補位。
- 地區三選一探索，以及包含獎勵和可見風險的卡包。
- Runtime 生成基地、建造卡、建築等級、獨立製作列、成本保留與溢出製造力。
- 可支付所有成本的永久食物，以及只能抵銷輪末固定消耗的臨時食物。
- 將建築、互動狀態與殭屍威脅集中在同一空間的中央基地畫面。

## 主題與情緒要求

- 生存應艱難，但策略資訊必須清楚可讀。
- 探索必須同時傳達希望與不安。
- 基地應讓人感覺有人居住且值得保護，而不是抽象的功能選單。
- 殭屍不只是敵人，也代表探索風險與污染所造成的後果。
- 成長應呈現得來不易的穩定，而不是毫無代價的力量幻想。

以上是體驗要求，不是已定案的畫風。Art Bible 將負責定義 Visual Identity Anchor、
色彩系統、形狀語言、繪製方式與資產製作標準。

## 目標平台與操作

- **主要平台：** PC。
- **主要輸入：** 滑鼠優先。
- **主要呈現：** 卡牌、可點擊的中央基地、建築詳情、地區選擇與威脅資訊。
- **閱讀要求：** 卡牌插圖與語意資訊在手牌和牌組預覽尺寸下仍必須清楚。

## 單局目標

暫定勝利條件為讓基地存活至指定天數。確切天數，以及生存期限結束時是否
還有額外的最終目標，目前尚未定案。

失敗代表基地的生存狀態崩潰。生命、士氣、基地耐久或其他失敗門檻的最終
組合仍待確認。

## 目前範圍

目前可玩基礎集中於：

- 正規牌組合法性與固定輪次節奏。
- 食物、資源、戰鬥值與臨時食物。
- 殭屍附加卡與基地威脅。
- 事件、探索地區與卡包。
- 卡牌倉庫、合法替換、耗盡與空位補位。
- Runtime 建築、施工工作、製作佇列與製造力。

## 尚未定案

- 勝利所需的確切存活天數。
- 最終失敗條件與基地耐久的呈現方式。
- 完整士氣、倖存者、傷口、藍圖與建築受損系統。
- 正式事件權重與長期難度曲線。
- 局外成長與其他勝利路線。
- 最終視覺識別、血腥程度與角色呈現方式。
