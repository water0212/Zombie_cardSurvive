# Zombie Card Survive Art Bible

> **Art Director Sign-Off (AD-ART-BIBLE)**: Skipped - Lean mode.
> **Scoped Visual Core V2**: APPROVED 2026-07-06

本文件定義 Zombie Card Survive 的視覺限制與製作判準。所有美術資產、
UI 視覺與生圖提示詞都必須遵守已核准章節；尚未完成的章節不得視為定案。

> **V2 修訂優先規則：** 2026-07-06 起，卡牌採用徽記式剪影，事件與地區
> 採用場景式剪影。黯淡灰黑、帶破損與污垢的底材承載單一語意色。
> 本規則若與後文的粗墨孔版插畫、人物內部細節或舊試產要求衝突，
> 一律以本修訂為準；衝突章節待後續逐節重寫。

### V2 已鎖定視覺核心

1. **卡牌用徽記式剪影：** 以一個封閉主剪影表達人物、動作與關鍵道具，
   不使用臉部、衣紋、材質或場景細節。
2. **事件與地區用場景式剪影：** 以地平線、地標與最多三層大型剪影表達
   地點或情境，不退回完整概念插畫。
3. **末日底材：** 背景以黯淡灰黑為主，可有邊緣剝落、裂痕、刮擦、煙灰
   與乾燥污垢，但不得穿過主要辨識輪廓。
4. **單一語意色：** 每張圖以一種低彩度分類色作為徽記底或主剪影色；
   類型仍須由剪影與分類圖示辨識，不得只依靠顏色。
5. **縮圖優先：** 在 66×54 尺寸仍須一眼辨認主動作；看不懂時調整大形
   與負空間，不增加內部細節。

## 1. 視覺識別宣言

### 方向名稱

**末日勤務手冊**

### 核心視覺規則

> **所有圖像先以剪影讓命令一眼可懂：卡牌凝縮成徽記，事件與地區展開成
> 場景；灰黑破損底材承載單一語意色，留下末日中的磨耗。**

### 支持原則

#### 1.1 規則必須像命令一樣先被看懂

服務「受限制的牌組規劃」支柱。

**設計判準：** 移除文字後，玩家仍能從主體輪廓、卡框和圖示辨認卡牌類型
與主要用途。

#### 1.2 每份希望都必須留下風險痕跡

服務「探索同時帶來希望與麻煩」支柱。

**設計判準：** 探索收益旁必須存在警示章、斜紋、破損或威脅符號，
不能呈現為無代價獎勵。

#### 1.3 短期資源是磨損，長期建設是藍圖

服務「犧牲現在以建設未來」支柱。

**設計判準：** 消耗品使用磨損實物和粗糙墨面；永久建設使用較完整的
工程線條與模組結構。

### 視覺敘事框架：末日檔案館

#### 核心隱喻

每一次遊玩都是一本獨立的基地勤務紀錄或回憶錄。失敗不代表該局被抹除，
而是該基地的故事已經結束並被封存；後來的人能透過過往紀錄取得情報，
讓下一次生存嘗試走得更遠。

#### 紀錄保管者

遊玩前的主畫面位於安靜、昏暖的檔案室或私人書房。背景中有一名年老的
紀錄保管者在書架與書桌之間緩慢活動。他的真實身分保持模糊，不明確宣告
為玩家角色的未來版本，以避免不同失敗紀錄之間產生敘事矛盾。

老人是視覺敘事角色，不取代清楚的畫面選單。玩家不需要追著角色點擊；
開始遊戲、繼續遊戲、歷史紀錄與設定仍使用穩定、可預期的 UI 操作。

#### 單局生命週期

- **開始遊戲：** 老人從空白書區取下一本尚未書寫的新冊。
- **繼續遊戲：** 老人取下帶有書籤、尚未封存的勤務紀錄。
- **進入單局：** 書本在桌面翻開，鏡頭接近其中一頁；紙張、藍圖與墨線
  擴展為遊戲中的基地畫面與 UI。翻頁過程可遮蔽載入。
- **歷史紀錄：** 已結束的單局以封存書冊保留在書架上，書脊可顯示日期、
  基地名稱、存活天數或代表成果的符號。

#### Roguelite 知識繼承

局外成長優先表現為前人留下的知識，而不是沒有來源的永久數值提升。
可使用的視覺載體包括：

- 地圖上的手寫路線與地區情報標籤。
- 殭屍弱點、事件結果與風險註記。
- 建築藍圖夾頁與新配方索引。
- 倖存者名單、卡牌註解與分類書籤。
- 書架上逐漸增加的封存紀錄。

**設計判準：** 每項局外解鎖都應能回答「這項知識是由哪一份過往紀錄留下」，
避免將成長只呈現為脫離世界觀的百分比加成。

## 2. 情緒與氛圍

所有狀態都使用「末日勤務手冊」的共同語言：光影以少量明暗階段和大色塊
表現，不使用覆蓋資訊的全畫面濾鏡。情緒效果只能作用於背景、插圖、邊框、
圖示和提示區，不能遮蔽文字、數值或操作按鈕。

### 2.1 基地管理／一般回合：受控的戒備

基地仍在正常運作，但沒有人真正放鬆。

- **圖片與光線：** 骨白紙面、冷灰色基地、陰天漫射光和少量暖色工作燈。
- **UI 載體：** 整齊的值勤表格、粗黑欄線與反覆擦改留下的磨痕。
- **動態節奏：** 克制、規律；建築維持小幅運作，標籤與紙張只有輕微晃動。
- **限制：** 不大量使用警示紅，避免平常畫面持續處於最高警報狀態。

### 2.2 事件選擇：冷靜的裁決

玩家正在閱讀事件報告，並對後果負責。

- **圖片與光線：** 事件以事故報告、證詞或現場紀錄呈現，使用中性工作光。
- **UI 載體：** 三個選項具有穩定編號、成本欄與結果提示；正面結果使用
  配給黃或藍圖線，風險使用小面積紅章、斜紋或缺角。
- **動態節奏：** 停頓、比較、確認；選項回饋清楚但不催促玩家。
- **限制：** 不以模糊文字、隱藏成本或難以辨識的版面製造緊張。

### 2.3 探索地區選擇：帶風險的期待

外面的世界危險，但可能存在基地迫切需要的希望。

- **圖片與光線：** 比基地畫面明亮、開闊；清晨冷光搭配一小段暖色地平線。
- **UI 載體：** 地圖路線、預期收益圖示與危險度印章。未封口的路線箭頭
  代表結果未知，終點由小面積警示章壓住。
- **動態節奏：** 懸停、向前；讓玩家有想前往的吸引力，也能看見代價。
- **限制：** 警示效果不得遮住地區主圖或主要地標。

### 2.4 殭屍威脅／戰鬥配置：迫切但清醒的決斷

玩家需要立即處理威脅，但仍有時間計算與重新分配戰鬥值。

- **圖片與光線：** 冷白硬光、高對比；殭屍使用破碎、前傾的輪廓。
- **UI 載體：** 紅色警戒斜帶由邊緣朝威脅區收攏。可擊殺目標使用勾選、
  封鎖線或目標章；戰鬥值不足時顯示缺口數字與警告符號。
- **動態節奏：** 高張力但可控，回饋迅速且允許玩家取消分配。
- **限制：** 不使用持續閃爍、全螢幕紅色濾鏡或遮蔽操作的畫面震動。

### 2.5 製作／建築完成：付出後的踏實進展

基地不是突然變得強大，而是終於多了一項可靠能力。

- **圖片與光線：** 偏暖工作光；斷裂藍圖線逐段連接，形成完整建築或物品。
- **UI 載體：** 使用配給黃或醫療青的完成章，零件線對齊、結構閉合、
  工作燈亮起。
- **動態節奏：** 穩定上升、短促而明確。
- **限制：** 保留舊有磨痕，不使用金色爆光、寶箱噴射或大量粒子。

### 2.6 輪末短缺／壓力累積：資源將斷的窒迫

玩家清楚看見下一輪可能無法維持基地，而不是在結算後才突然受罰。

- **圖片與光線：** 冷色暮光；紙面轉冷，黑色盤點欄由邊緣向內收窄。
- **UI 載體：** 短缺數字、受影響項目與預計後果保持可見；警示紅只標記
  真正不足的資源與即將發生的代價。
- **動態節奏：** 持續升壓；供應刻度逐格變空，表格欄位依序被劃除。
- **限制：** 侵蝕效果只能壓縮裝飾留白，不得覆蓋文字、數值或按鈕。

### 2.7 敗北／紀錄封存：確認基地失守後的寂靜

敗北不是仍在發生的激烈危機，而是基地運作已經停止、結果無法挽回的安靜。

- **圖片與光線：** 背景轉為灰冷、低彩度與低對比；鮮紅警報隨可操作時間
  結束而消退。
- **UI 載體：** 最後一頁記錄存活天數、失敗原因與本局取得的重要情報，
  並蓋上暗紅或墨黑、邊緣乾裂缺墨的「紀錄封存」章。
- **動態節奏：** 歸零、靜止；基地動畫與燈光停止，書本緩慢闔上並放回書架。
- **限制：** 結算文字和按鈕仍需清楚；演出必須呈現本局留下的情報或解鎖，
  不得暗示本局毫無價值。

### 2.8 勝利／存活指定天數：不張揚的倖存自豪

勝利代表這座基地成功撐了下來，而不是已經征服末日。

- **圖片與光線：** 暖色日出照進檔案室；基地藍圖穿過舊折痕並延伸至頁外。
- **UI 載體：** 最後一頁記錄存活天數、重要人物、建築與關鍵決策，
  使用「勤務完成」或「紀錄完成」章。
- **動態節奏：** 穩定、釋放；老人闔上書本，將它放入與失敗紀錄不同的位置。
- **限制：** 污漬、修補和傷痕不得消失，避免把勝利呈現成世界已恢復和平。

## 3. 形狀語言

### 3.1 核心規則

1. **完整、直立、方正**代表基地、秩序與當下可用資源。
2. **破裂、傾斜、不對稱**代表殭屍、感染、風險與資源壓力。
3. **虛線、未閉合、向外擴建**代表規劃、施工與犧牲後的未來。
4. 閱讀順序固定為：**剪影、大色塊、功能線條、磨損裝飾**。

污漬、印章與紙張紋理不得破壞功能輪廓。玩家即使在灰階與縮圖狀態下，
仍應先看懂陣營、物件類型和主要用途。

### 3.2 倖存者

倖存者以矩形、梯形和短直線為主。頭、軀幹與雙腳保持完整相連，重心位於
雙腳之間，肩線清楚。身分依靠體塊比例、姿勢和一件主要工具表達，
不依賴衣服花紋或臉部細節；臉部最多保留一條眉眼線或鼻影。

| 類型 | 縮圖剪影 |
|---|---|
| 工人／工匠 | 寬矩形軀幹、低重心、平行站姿；方形工具箱與短柄工具 |
| 探索者 | 窄身前傾，背包形成背部圓凸，搭配一條明確的斜向探路工具 |
| 守衛 | 倒梯形肩部、A 字穩定站姿，武器或盾牌形成單一垂直塊 |
| 醫護 | 直立圓角軀幹、圓角醫療包，包面使用等臂十字鏤空 |
| 指揮／規劃者 | 高窄直立體塊、胸前記錄板、短直指示臂與水平帽緣 |

工具必須接近身體並形成主剪影的一部分，避免以縮小後會消失的細長零件
作為唯一職業特徵。

### 3.3 殭屍

殭屍必須在無色狀態下與倖存者形成差異：

- 頭部向前偏離肩軸，脊椎形成明顯 C 形。
- 左右肩不同高，手肘突出主體，雙腳方向不一致。
- 外輪廓至少有一處缺口或鋸齒，但不依靠大量破衣細節辨識。
- 不使用完整直立、對稱肩線、整齊裝備塊或穩定雙腳站姿。

| 類型 | 縮圖剪影 |
|---|---|
| 一般型 | 中度 C 形、單臂下垂、單腳拖行，頭部是最前方的小凸塊 |
| 高速型 | 長而低的前衝三角形，四肢形成斜線，避免垂直站姿 |
| 重型 | 寬大不對稱梯形軀幹、短腿，頭陷入高低不同的肩膀之間 |
| 伏地型 | 水平輪廓、頭與單肩抬高、三點接地 |

受傷倖存者不得使用與殭屍相同的 C 形崩解姿勢。受傷狀態應以支撐動作、
繃帶圖符或傷口章表達，保持人形結構完整。

### 3.4 建築與地區

每棟建築由三個部分構成：**基座、核心體塊、功能頂件**。同類建築可共用
基座，但功能頂件必須能單獨辨識用途，例如廚房煙囪、工作台工具架或
醫療站十字符號。

- 實線表示已存在的成果。
- 虛線表示規劃或尚未完成的未來。
- 斜線網格只表示施工中的區域。

| 狀態 | 形狀表現 |
|---|---|
| 空地 | 虛線地基、四個短樁與最多一堆材料；不超過完成體積的 35% |
| 建造中 | 顯示完成輪廓的 50% 至 70%，一側開放鷹架並加入大型斜撐 |
| 運作中 | 外輪廓完整閉合，只保留一個功能頂件與一個運作訊號 |
| 升級中 | 既有建築保持實線，新部分以外擴虛線塊呈現 |

每個探索地區鎖定一種不可互換的主要天際線，例如階梯高樓、雙煙囪、
圓頂水塔或斷裂山脊。地區圖只使用一個主地標與最多兩個支撐形，
不得依賴招牌文字或大量小道具辨識。

### 3.5 卡牌與 UI 形狀

- 所有卡牌共用約 160×220 的直式矩形家族：三個直角、右上角切角。
- 外框在最終顯示尺寸約 3 px，資訊分隔線約 2 px。
- 費用固定在左上角，分類票籤固定在右上切角，兩者不得互相競爭。
- 插圖區固定約 133×107，底部保留穩定的規則文字帶。
- 不使用卡中卡；資訊依靠橫線、留白和紙面色塊分隔。
- 印章只表示狀態或裁決，每張卡最多一枚，旋轉不超過正負 3 度。
- 磨損只出現在外框和空白區，不得穿過數值、標題或分類標記。
- 滑鼠懸停與選取使用外移描邊及票籤位移，不得只改變顏色。

角色剪影、費用與分類標記是封閉實心的主角形；藍圖線、背景建築和磨損
是細線、虛線或開放輪廓的支援形。卡框不得使用奇幻卷軸、寶石或雕花。

### 3.6 卡牌分類備援標記

所有分類共用相同票籤位置，以**實心圖符、票籤局部缺口和文字名稱**
形成三重辨識；分類不得改變整張卡的外形。

| 類型 | 圖符 |
|---|---|
| 食物 | 半圓碗形與一條蒸氣線 |
| 資源 | 三條堆疊材料塊 |
| 戰鬥 | 兩條交叉粗斜線 |
| 探索 | 中空指南針菱形 |
| 建造 | L 形角尺與一條斜撐 |
| 特殊 | 六向實心放射形 |
| 殭屍 | 前伸頭部與 C 形背部 |
| 傷口 | 中央斷裂的斜向繃帶 |

### 3.7 卡圖細節預算

以下限制以約 133×107 的最終卡圖顯示尺寸為基準：

- 主要人物或建築最多 1 個。
- 次要人物最多 1 個；群體事件最多使用 3 個合併背景剪影。
- 道具最多 2 件，其中只有 1 件可以脫離主體。
- 景深最多 3 層：前景記號、主體、背景大塊。
- 主體占畫面 55% 至 70%，群體構圖不得超過 78%。
- 總負空間至少 25%，其中至少 15% 是連續空白。
- 主體距圖框至少 4 px，頭部與關鍵工具周圍至少保留 6 px。
- 主輪廓約 3 px、內部線約 2 px、藍圖線約 1 px。
- 最多 4 個灰階明度、12 條內部描述線與 3 組磨損紋理。
- 禁止微型文字、散落彈殼、重複磚紋及逐件描繪背包內容。

### 3.8 灰階與縮圖驗證

- 純黑剪影下仍可區分倖存者、殭屍與建築。
- 倖存者職業在 66×54 下仍可依姿勢與工具辨識。
- 卡圖縮至 33×27 時，主事件仍能用一句話描述。
- 卡牌縮至約 40×55 時，八種分類標記仍不可混淆。
- 轉為黑、中灰、白三值後，主體必須先於背景被看見。
- 加入 1 px 模糊後，角色頭部、關鍵工具與殭屍姿勢不能黏合。
- 移除所有色彩後，懸停、選取、傷口與殭屍狀態仍可辨識。
- 五人快速測試中，至少四人須在兩秒內辨認陣營與卡牌類型。

正式製作前必須先完成一張純灰階驗證表，包含五種倖存者、四種殭屍、
四個建築階段、八個分類標記與共用卡框。未通過辨識測試時，只調整剪影
和大形，不以增加細節補救。

## 4. 色彩系統

### 4.1 核心調色盤

採用七色限定系統。檔案紙與炭黑墨承擔主要資訊，彩色只負責分類、狀態、
局部印章與少量情緒提示。

| 色彩 | Hex | 語意角色 | 最大覆蓋 |
|---|---|---|---:|
| 檔案紙 | #E6DDC5 | 卡面、頁面、資訊底色 | 60% 至 80% |
| 炭黑墨 | #252622 | 正文、數值、輪廓、主圖形 | 12% 至 22% |
| 結構灰 | #5E625D | 基地結構、資源、次要資訊 | 8% 至 15% |
| 感染紅 | #B53A32 | 殭屍、傷口、立即危險 | 通常不超過 8%，戰鬥不超過 15% |
| 補給黃 | #C79A24 | 食物、補給、消耗與短缺 | 不超過 10% |
| 藍圖藍 | #2F7185 | 建造、醫療、能量、穩定 | 不超過 10% |
| 未知紫 | #685B86 | 探索、未知結果、士氣 | 不超過 8% |

一般畫面的彩色總覆蓋不超過 20%，戰鬥狀態最高 25%。明度順序固定為
檔案紙、補給黃、語意中間色、炭黑墨。不設常駐綠色，避免建立紅綠互斥判讀。
衍生淺色以網點露出紙色，不新增實色。

### 4.2 食物與資源

- **永久食物：** 補給黃實色、完整直立容器圖示與實心底線。
- **臨時食物：** 補給黃斜線網紋、虛線邊框、沙漏或撕角圖示。
- **資源：** 結構灰、材料堆疊或螺栓圖示與交叉排線。

食物與資源不只依靠黃色和灰色區分，還必須搭配圖示、容器形狀與紋理。
資材種類異質，不使用額外專色暗示它們是同一種物質。

### 4.3 系統與卡牌語意

| 系統／卡牌 | 色彩 | 必要備援 |
|---|---|---|
| 戰鬥值 | 炭黑墨 | 武器圖示與固定數值框，不預設為紅色 |
| 能量 | 藍圖藍 | 閃電圖示與完整方框 |
| 士氣 | 未知紫 | 旗幟與放射印章 |
| 探索 | 未知紫 | 羅盤、點線路徑與開放框 |
| 建造／製作 | 藍圖藍 | 格線、工具與直角模組 |
| 殭屍 | 感染紅 | 破裂斜框與雙斜線 |
| 傷口 | 感染紅 | 繃帶與局部切痕，不使用殭屍破框 |
| 預設／基地牌 | 紙、墨、灰，局部藍 | 完整方正框 |
| 探索風險牌 | 未知紫，確認危險後才加紅 | 點線與不對稱框 |

未知紫區分「尚未揭露的風險」，感染紅只表示「已確認且迫近的危險」。
士氣和探索雖共用紫色，士氣固定使用旗幟與放射章，探索固定使用羅盤與
點線路徑。

### 4.4 卡牌品質

| 品質 | 色彩 | 無色辨識 |
|---|---|---|
| 普通 | 結構灰 | 單線框與 1 個索引缺口 |
| 良質 | 藍圖藍 | 雙線框與 2 個索引缺口 |
| 稀有 | 未知紫 | 三重登錄記號與 3 個缺口 |
| 唯一／特殊 | 炭黑反白章 | 4 個缺口，不新增專色 |

稀有度、威脅、傷口與暫時性等重要資訊，在移除色彩後仍必須由框形、
圖示、數量與紋理辨識。

### 4.5 遊戲狀態用色

- **基地：** 紙色主導，灰與藍維持低比例，紅色只標示未處理警告。
- **事件：** 墨色表格與灰色案卷為主，結果使用單一局部裁決章。
- **探索：** 增加紫色點線與開放框，出現補給時才加入黃色。
- **戰鬥：** 紅色集中在敵方欄位、方向箭頭與破框，資訊底保持紙色。
- **建設完成：** 藍圖線閉合並加上實心核准章。
- **短缺：** 黃色供應區縮小，墨色排線與空白缺口增加，嚴重時才加入紅章。
- **敗北：** 移除多數彩色，以墨和灰封卷，只保留小型暗紅封存章。
- **勝利：** 紙、墨、藍為主，搭配少量黃色完成章。

禁止使用全螢幕染色或濾鏡改變情緒。

### 4.6 地區色溫

地區只調整既有顏色的比例，不新增區域專色。

| 地區 | 色彩傾向 |
|---|---|
| 廢棄超市 | 偏暖，補給黃比例最高，藍色只作冷藏與標示線 |
| 住宅區 | 紙色與灰色為主，少量褪色黃，紅色限於破壞或感染 |
| 加油站 | 冷藍結構配黃色警戒標，紅色只表示火災或殭屍威脅 |
| 學校 | 冷而清楚，藍圖藍、紙色與規整墨線主導 |
| 倉庫 | 中性，結構灰與炭黑墨比例最高，藍色標示盤點與路線 |
| 軍事基地 | 冷、高對比，灰藍結構搭配局部紅色限制章 |

### 4.7 UI 狀態

- 正文和重要數值使用炭黑墨搭配檔案紙。
- 結構灰只用於次要文字，不再降低透明度。
- 彩色實底不承載一般尺寸正文；文字應回到紙色標籤。
- 背景只使用紙色或灰色網點分區，不使用漸層。
- **Hover：** 增加 2 px 墨框與游標側登錄記號。
- **Selected：** 使用 3 px 墨框、藍色側條與勾選章。
- **Unavailable：** 使用灰色交叉排線、封鎖圖示與斜劃，標題仍保持墨色。
- **Reserved Cost：** 保留原資源色，加入括號框、鎖頭和 50% 網點。
- **Temporary Food：** 黃色斜線網紋加沙漏，不只降低透明度。
- **注意：** 黃色三角章。
- **危險：** 紅色雙斜線。
- **緊急：** 紅色破框加炭黑反白標題。

正文對比至少 4.5:1，大型文字至少 3:1。炭黑墨搭配檔案紙是預設正文組合。

### 4.8 色覺與灰階安全

- 系統不建立紅綠互斥判斷。
- 感染紅固定搭配破裂斜框、雙斜線和威脅圖示。
- 藍圖藍使用完整直角與實線；未知紫使用點線與開放輪廓。
- 補給黃只表示補給或注意，不單獨表示安全；兩者分別搭配容器和三角圖示。
- 灰階下彩色語意仍必須由形狀、圖示、紋理和文字標籤辨識。
- 驗證需包含紅色弱、綠色弱、純灰階和 160×220 原生尺寸。

### 4.9 印刷與手冊質感

- 每張卡圖最多使用檔案紙、炭黑墨和兩種彩墨，常態建議只有一種彩墨。
- 網點只使用 25%、50% 和 75% 三級；最終卡面點距不得小於 4 px。
- 小字、數值、圖示與 2 px 以下線條禁止使用網點。
- 炭黑墨可以覆印彩色；彩色彼此最多重疊兩層，重疊區不超過插圖 10%。
- 紅色不得與藍色或紫色大面積覆印。
- 插圖的刻意套印偏移最多 1 px，純裝飾磨損最多 2 px。
- 文字、數值、圖示與卡框必須零偏移。
- 磨損不超過卡面 8%，且不得穿過費用、名稱、數值或狀態圖示。
- 禁止漸層、柔光、彩色陰影和照片式細密抖色。

### 4.10 驗證要求

- 關閉色彩後仍能辨識所有系統、品質與狀態。
- 通過紅色弱、綠色弱與純灰階模擬。
- 正文對比至少 4.5:1，大型文字至少 3:1。
- 單卡不超過檔案紙、炭黑墨與兩種彩墨。
- 暫時／永久、保留／可用、Hover／Selected 均不依賴顏色。
- 地區差異來自色彩比例和紋理，而不是新增專色。
- 畫面不使用漸層、全螢幕染色或影響資訊的磨損。

色彩的總原則是：**紙、墨、灰建立檔案館秩序；黃、藍、紅、紫分別表示
補給、建設、危險與未知。彩色是第二層提示，形狀和圖示才是第一層資訊。**

### 4.11 核心繪製風格

正式媒材定義為：**粗墨筆加孔版套色的末日勤務手冊插畫**。

畫面使用乾澀粗線、平面大色塊、單色網點、藍圖線、印章和克制的紙張磨損，
所有裝飾都必須服從資訊辨識。

本風格明確排除：

- 寫實概念圖、照片拼貼和 3D 渲染。
- 動漫、油畫、水彩和仿製特定漫畫或藝術家。
- 柔光、漸層、寫實皮膚、照片噪點和複雜背景。
- 直接模仿《Slay the Spire》的筆觸、怪物比例或卡框裝飾。

《Slay the Spire》只作為卡牌資訊層級、固定閱讀順序和縮圖可讀性的參考。

### 4.12 繪製規則

以 266×214 卡圖母稿為基準：

- 外輪廓 5 至 7 px，內部線 2 至 3 px。
- 線條可有輕微乾澀抖動，但主要輪廓必須閉合。
- 平塗最多四階灰；網點只用於陰影，固定 45 度，覆蓋不超過 20%。
- 磨損集中在邊緣，面積不超過 10%，不得破壞臉、手或關鍵道具。
- 一般使用平視或輕微四分之三視角；危險畫面傾斜不超過 10 度。
- 禁止魚眼、極端廣角和難以統一的戲劇透視。
- 人物約六頭身，臉部只用 3 至 5 個墨色記號，手部可使用塊面簡化。
- 環境最多三層景深與兩件敘事道具，禁止形成雜物牆。

### 4.13 不同資產的處理

- **卡牌插圖：** 最終顯示約 133×107；單一主體、最多一名次要人物、
  最多兩件道具，主體占 55% 至 70%，留白至少 25%。
- **地區插圖：** 一個主要地標與一條視覺動線，使用前、中、後三層，
  不以大量小建築製造全景。
- **建築圖片：** 固定平正或四分之三視角，入口、功能頂件和建築狀態
  必須一眼可讀。
- **倖存者肖像：** 完整、直立的胸像，以一件職業物品辨識。
- **殭屍肖像：** 破裂、傾斜、不對稱的胸像，以姿勢和剪影辨識。
- **檔案館主畫面：** 書架、桌面、記錄冊與身分模糊的年長紀錄保管者
  為核心，至少保留 35% 乾淨選單區，不在圖片中生成選單文字。

### 4.14 世界地域與血腥尺度

世界設定為：**災變發生後 1 至 3 年的北美五大湖鏽帶虛構城市與周邊郡鎮。**

可使用的地域線索包括磚造學校、工業倉庫、鐵路、老舊住宅、獨立加油站、
大型停車場、水塔、筒倉、煙囪、木造電線桿、消防栓、郵箱、皮卡、校車
與貨運車。軍事基地可表現為國民兵、後備軍設施或廢棄空軍基地；學校可
表現為職業高中、技術學校或社區大學。

招牌只生成可辨識的形狀，不由 AI 產生可讀文字；正式文字由 Unity 或
美術後製加入。

血腥尺度採低至中度：

- 允許撕裂衣物、破裂輪廓、拖行姿勢、紅墨污跡和剪影缺口。
- 不描繪傷口內部、內臟、肢解斷面或寫實血肉。
- 殭屍主要依靠姿勢、不對稱和感染符號辨識，不依靠血腥細節。

    最多再使用兩種指定彩墨。

### 4.16 生圖後正規化

1. 以目標尺寸的 2 至 4 倍生成。
2. 裁切到資產需要的比例，確認主體與留白位置。
3. 卡圖縮至 266×214 的 2 倍工作尺寸，再輸出 266×214 母稿。
4. 將色彩限制到本章七色，並限制為最多四階灰。
5. 清理輪廓、多餘肢體、額外物件、色盤污染與假文字。
6. 縮至實際 133×107 顯示尺寸進行辨識測試。
7. 不透明卡圖輸出 sRGB PNG；只有獨立剪影資產使用透明 PNG。
8. Unity 匯入設定為 Sprite、關閉 Mipmap、Max Size 512，並統一收入
   對應的 Sprite Atlas。

### 4.17 六件試產與通過條件

第一批只製作：

1. 廢棄超市地區。
2. 普通殭屍。
3. 烹飪卡。
4. 工作台建築。
5. 探索者倖存者。
6. 末日檔案館主畫面。

六件資產並排時必須像來自同一本勤務手冊；縮圖一秒內可辨識主體，
符合色盤、人物數量、物件數量、形狀語言和血腥限制。任何假文字、漸層、
超額細節、未核准色彩、錯誤肢體或背景過密都視為未通過。

正式批量生產前，必須先從六件試產中選出至少兩張合格基準圖，鎖定提示詞
版本和正規化流程，再讓後續資產以基準圖作為一致性參考。
