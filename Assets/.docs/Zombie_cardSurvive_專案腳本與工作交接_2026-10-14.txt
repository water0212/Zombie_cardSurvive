======================================================================
一、專案摘要
======================================================================

本作是基地指揮者視角的末日生存卡牌 Roguelite。玩家透過卡組、建築、探索、
事件、食物／資源／戰鬥值調度與士氣管理，使基地度過長期生存壓力。

目前已具備可玩的核心循環：
卡牌與牌組 → 探索／卡包 → 事件 → 建築施工與製作 → 殭屍威脅與輪末結算。
士氣已成為正式失敗條件，具有永久上限損傷、不可逆 Stage 與基地崩潰。

目前最新完成的大型工作是：
BUILDING-UI-001「建築詳情與書籤式功能面板」。
狀態為 Complete with Notes，已通過使用者小範圍 Play 與輕量結案 Review。

三、程式架構總覽
======================================================================

整體採「Data / Runtime / UI / Editor」分工：

- Data：ScriptableObject 與序列化設定，只描述規則和內容。
- Runtime：一局遊戲的權威狀態、驗證、支付與結算。
- UI：讀取 Runtime、顯示資料、把玩家要求送給 Runtime；不可自行修改經濟狀態。
- Editor：建立／更新 Asset、Prefab、場景引用的可重複套用工具。

重要原則：

- 不要手寫 Unity .asset YAML，使用 Unity Editor API 或既有 Setup Utility。
- UI 不可保存第二份資源、製作工作、士氣或卡牌權威資料。
- 事件、探索與建築等全螢幕流程必須遵守共同流程鎖定。
- Setup Utility 應保持冪等，可重複執行而不生成重複物件。
- 專案工作樹目前有大量尚未提交的修改與新增檔案；不可重置、覆蓋或清除。

【A. 回合與 Run 流程】Scripts/Run/

- RunPhase.cs
  定義目前局內階段。
- RunPhaseController.cs
  控制 Turn／Round／事件／建築結算／失敗停止點；士氣崩潰後阻止繼續流程。
- RoundEndResolver.cs
  輪末核心結算：殭屍擊殺與漏防、下輪效果、食物、士氣批次、Stage 效果等。
- RoundEndReport.cs
  保存輪末因果結果，供 Debug 與未來正式結算回饋使用。
- RunPhaseDebugView.cs
  開發期流程狀態顯示。

【B. 全局數值與失敗條件】Scripts/ValueSystems/

- FoodSystem.cs
  永久食物、臨時食物、保留量、消耗與容量的權威。
- FoodPlanSystem.cs
  標準供應／鼓舞餐點；正規化舊方案並計算輪末需求。
  已知修正：同一正規化方案不可再次消耗本輪調整機會。
- ResourceSystem.cs
  資源數值、保留、消耗與狀態通知。
- CombatSystem.cs
  戰鬥值、殭屍擊殺分配及場上威脅處理。
- EnergySystem.cs
  基礎最大能量、Stage 修正、Turn 補滿與最低 0 的處理。
- MoraleSystem.cs
  士氣唯一權威：Current、Maximum、不可逆 Stage、批次提交與基地崩潰。
- MoralePyramidSystem.cs
  鎖定本局 Profile Snapshot，切換並整組取代 Stage 效果。
- MoralePyramidProfileData.cs
  定義三階士氣 Profile 的顯示資料和效果。
- MoraleBatchResult.cs / MoraleChangeResult.cs / MoraleCollapseStage.cs
  士氣結算資料、變更結果和階段型別。
- ZombieThreatRuntime.cs
  場上殭屍威脅的 Runtime 狀態與完整反應窗口資料。
- NextRoundEffectSystem.cs
  卡牌、事件、殭屍共用的下輪效果排程、啟用與消耗。
- RoundFoodConsumptionResult.cs / ValueConsumptionResult.cs
  食物及通用數值消耗結果。
- TurnProductionEffect.cs
  Turn 產出效果資料。

士氣現行規則：
- 新局 100／100。
- 士氣低於 70 進 Stage 1，低於 35 進 Stage 2；跨越後不可回復舊 Stage。
- 士氣歸 0 時基地崩潰，Run 進入 Failed。
- 食物短缺每缺 1 扣 3 士氣，單輪最多扣 15。
- 鼓舞餐點成功恢復 5；高士氣自然回落每輪最多 3，最低停在 70。
- Demo Profile：Stage 0 無效果、Stage 1 每輪資源 -1、Stage 2 最大能量 -1。

重要規則：
- 手動與抽到自動打出共用 Costs → Effects → 使用次數 → 棄牌／耗盡流程。
- 自動打出免付 EnergyCost，但一般 Cost 仍必須支付；Cost 不足時留在手牌。
- 留在手牌後可於同 Turn 改為手動打出，屆時需要支付能量。
- 使用次數耗盡後自然進入耗盡區，不為殭屍卡建立額外特例。
