# Asset Manifest

## Status Definitions

- `Needed`: specification exists, but no production-ready asset has been delivered.
- `Needs Redesign`: an older trial asset exists, but it does not meet the current visual direction.
- `In Progress`: production has started and the deliverable is not ready for review.
- `Done`: deliverable exists and is ready for project use.
- `Approved`: deliverable passed art-direction and in-engine review.
