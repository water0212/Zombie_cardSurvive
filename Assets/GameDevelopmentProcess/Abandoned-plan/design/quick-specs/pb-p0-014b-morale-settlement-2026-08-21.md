# Quick Design Spec: PB-P0-014B 食物、事件與輪末士氣批次結算

**Type**: Addition  
**System**: 士氣 / 食物 / 事件 / 輪末  
**GDD Reference**: `Docs/GameDesign/ZombieSurvivalCard_GDD.md` 第 30.5、30.7、30.9 節  
**Date**: 2026-08-21

## Change Summary

把既有逐項立即改變士氣的來源遷移成完整交易批次：同一輪末、事件選項、卡牌效果或探索結果中的士氣增減先記錄並合併，再只提交一次門檻與基地崩潰判定。同時移除玩家可選的緊縮配給，將豐盛供應改為只能用永久食物支付的鼓舞餐點。

## Motivation

逐項立即提交會讓同一交易因效果排列順序產生不同的不可逆降階結果，也無法向玩家清楚說明最後一次士氣變化的各項原因。鼓舞餐點則必須與基地固定需求分開，避免臨時食物支付士氣恢復，並確保不足時不發生部分扣款或部分恢復。

## New Rules / Values

### 食物短缺

- 固定需求先使用臨時食物，再使用未被保留的永久食物。
- 短缺士氣損失為 `min(短缺食物 × 3, 15)`。
- `15` 只限制食物短缺來源，不限制同輪其他士氣損失。

### 鼓舞餐點

令：

```text
D = 本輪固定食物需求（包含已鎖定的需求修正）
E = 結算時的 MaxEnergy
T = ceil(D × 1.2) + E
額外永久食物成本 = T - D
```

- `T` 是本輪總需求；固定需求 `D` 不會重複支付。
- 固定需求有短缺時，本輪鼓舞餐點取消。
- 額外成本只接受未被保留的永久食物，臨時食物不能支付。
- 額外成本不足時不扣款、不恢復士氣。
- 成功後恢復 5 士氣，每輪最多結算一次。
- 士氣已達 `MaximumMorale` 時不扣額外成本。
- 士氣接近上限時仍支付完整成本，實際恢復值受上限限制。
- 鼓舞計畫持續生效，直到玩家改回標準供應；當輪失敗不自動切換計畫。

### 食物計畫相容性

- 玩家只看見標準供應與鼓舞餐點。
- 舊 `Tight` 序列化值暫時保留作相容入口，但 Runtime 一律正規化為標準供應，不再降低需求或士氣。
- 舊 `Generous` 數值身份保留，玩家顯示語意改為鼓舞餐點。

### 高士氣自然回落

- 每輪最多下降 3，最低停在 70。
- 先計算其他士氣來源的預計結果；只有預計士氣仍高於 70 時才建立自然回落項目。
- 自然回落與其他來源一起提交，且不得自行使士氣低於 70。

### 批次邊界

- 一個完整輪末是一個批次。
- 玩家確認的一個事件選項是一個批次。
- 一次完整卡牌效果或一次探索結果各是一個批次。
- 同一批次的正負士氣先合併，再進行一次上限、門檻、階段與崩潰判定。
- 事件付款或其他必要效果驗證失敗時，不提交該批士氣。

### 輪末來源順序與報告

輪末依序記錄既有存活殭屍傷害、食物短缺、鼓舞餐點與自然回落，再合併成一次士氣提交。報告至少保存：士氣前後值、上限前後值、各來源要求值、淨變化、實際變化、階段轉換與基地崩潰結果。

PB-P0-014B 只遷移目前的殭屍傷害，不修改攻擊時點、完整反應窗口或永久上限損傷；那些屬於 PB-P0-014C。

## Affected Systems

| System | Impact | Action Required |
|---|---|---|
| `MoraleSystem` | 接收帶逐項來源的批次 | 新增批次請求與結果，內部仍沿用 014A 的單次提交 |
| `RoundEndResolver` | 不再逐項直接扣士氣 | 建立單一輪末批次與因果報告 |
| `FoodPlanSystem` | 移除緊縮玩法 | 正規化舊值並計算鼓舞總需求／額外永久成本 |
| 事件效果 | 同一選項的士氣效果不可受排列影響 | 聚合後一次提交 |
| 卡牌／探索 | 提供可追溯來源 | 使用單項批次或完整交易批次 |
| Debug UI | 仍只需功能性資訊 | 顯示標準供應／鼓舞餐點語意；正式 UX 留待 014E |

## Out of Scope

- 殭屍完整反應窗口、永久士氣上限損傷與新殭屍資料。
- 士氣金字塔 Profile 與階段效果替換。
- 正式輪末預警、因果報告畫面與基地崩潰畫面。
- Save State 與長局平衡定案。

## Acceptance Criteria

- [x] 每缺 1 食物扣 3 士氣，單輪食物短缺損失最多 15。
- [x] 臨時食物可支付固定需求，但不能支付鼓舞餐點額外成本。
- [x] 鼓舞總需求符合 `ceil(D × 1.2) + MaxEnergy`，固定需求不重複支付。
- [x] 固定需求短缺或額外永久食物不足時，鼓舞不部分扣款、不部分恢復。
- [x] 鼓舞成功每輪只恢復 5 士氣；接近上限仍收完整成本，已達上限不收成本。
- [x] 舊緊縮配給不再降低需求或士氣，舊序列化值安全轉為標準供應。
- [x] 食物溢出與安全儲備不增加士氣。
- [x] 高士氣自然回落每輪最多 3 且不低於 70。
- [x] 同一批次的正負士氣先合併，結果不受效果排列影響。
- [x] 輪末只提交一次士氣狀態變化，報告保留逐項因果、淨變化、階段與崩潰結果。
- [x] 士氣歸零後不再進入事件、建築結算或下一輪。
- [x] PB-P0-014C 的殭屍時點與永久損傷仍未提前實作。
