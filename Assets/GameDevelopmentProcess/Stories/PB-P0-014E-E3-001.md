# PB-P0-014E-E3-001：重開局流程邊界與主選單占位場景

- 狀態：Planned，尚未實作／驗收。
- 建立：2026-10-31；範圍修訂：2026-11-02，依使用者明確決策取代原「完整方案卡 UI」要求。
- 前置：PB-P0-014D、既有 RunPhaseController；沿用 E1／E2 的權威與呈現分層。
- 流程規格：[Run Lifecycle](../Design/Run-Lifecycle.md)；順序：[Story-Sequence](../Story-Sequence.md)。

## 範圍

E3 是重開局與新局建立的流程部件，供未來正式主選單 UI 呼叫。建立與遊戲內 SampleScene 分離的主選單 Scene，占位可用白背景及最少的選擇／開始／狀態文字。建議場景名稱 MainMenu.unity，實際資產尚未建立；SampleScene 保持遊戲內場景，不改名、不重建原布局。

開局設定以士氣 Profile 為最小有效項目；使用者已確認這裡的 Stage 是 Profile，不是關卡，也不是直接指定 MoraleCollapseStage。為後續設定預留資料邊界，不憑空新增難度、劇本或其他玩法。

提供驗證選擇、要求開始新局、查詢轉場狀態的流程接口；具體程式名稱於實作時定案。占位操作只作驗收接線，不作正式 UI 設計。主選單沒有可操作 Run。

## 驗收條件

- [ ] 主選單占位與 SampleScene 是兩個獨立儲存的 Scene，能透過場景導覽切換，不在 Sample 裡疊出第二套主選單 HUD。
- [ ] 直接進占位主選單時，沒有舊局可操作，也不自動呼叫 StartRun 或套用 Profile 效果。
- [ ] 可選擇士氣 Profile 並發出開始要求；只有既有標準生存也可驗收。
- [ ] 缺少／無效 Profile 或場景設定時有明確失敗狀態，不啟動半套新局。
- [ ] 連按與載入中的重複要求不建立多個轉場。
- [ ] 未來正式 UI 可沿同一接口接線，占位按鈕不持有遊戲數值初始化邏輯。
- [ ] 保留 SampleScene 原手動排版、GUID、控制器及使用者程式調整。

## 不在範圍

正式主選單美術、完整 Profile 卡片布局、選單動畫、存檔／讀檔／終局、完整 HUD 重構。正式 UI 由 [PB-P3-005](PB-P3-005.md) 承接，不阻擋 E3。
