## 核心驗收路徑

SampleScene 遊戲內士氣崩潰畫面 → 切回白畫面主選單 Scene → 舊局資料完整清除、入口就緒 → 選擇士氣 Profile／合法開局設定 → 切到 SampleScene → 新 Run 可正常操作。

正式主選單 UI 不是驗收前置。占位只需能操作和觀察選擇、清理／載入狀態及失敗原因，不能為了正式卡片、排版或美術阻擋 E3。

## 驗收條件

- [ ] 上述路徑以真實 Scene 切換通過；不能僅在 SampleScene 隱藏／顯示面板模擬。
- [ ] 返回入口時沒有可操作舊 Run；清理未完成不能開始；確認後新局才初始化且只初始化一次。
- [ ] 新局士氣 100/100、Stage 0，原 Stage 1 資源效果、Stage 2 能量修正與其他舊局狀態均不殘留。
- [ ] 新局能正常完成打牌、事件、探索及輪末；再次崩潰後可再次返回並建立乾淨新局，訂閱／物件／鎖不增加。
- [ ] 缺 Profile、無效設定、連按、重複失敗通知及場景／初始化失敗時無半套可操作 Run。
- [ ] 以舊回呼延後到達案例驗證世代隔離，不改寫已返回主選單或新的 Run。
- [ ] E2 的略過輸入不穿透到主選單開始操作；選單開始輸入不穿透到 Gameplay 出牌／事件。
- [ ] E2 的跨階／70、69／35、34 等既有驗收依各 Story 保留；正式 UI 視覺矩陣不作本 Story 完成前置，未測項不能冒充通過。
- [ ] 交付 ScriptCodeReview/E3_API_Review.md，列場景流程圖、可供正式主選單 UI 呼叫的接口、單局清理清單、問題與證據。
