# PB-P0-014E-E3-002：跨 Scene 傳遞開局設定並初始化新 Run

- 狀態：Planned，尚未實作／驗收。
- 範圍修訂：2026-11-02。
- 前置：PB-P0-014E-E3-001。
- 流程規格：[Run Lifecycle](../Design/Run-Lifecycle.md)；玩法：[GDD](../GDD.md) §30.4；順序：[Story-Sequence](../Story-Sequence.md)。

## 範圍

主選單占位確認有效 Profile 後，以明確開局要求傳遞本次設定，切換到遊戲內 SampleScene，再由既有 RunPhaseController 初始化一個新 Run。跨場景只保留必要設定與轉場識別，不帶回舊局資料，也不以主選單 UI 直接寫入各資源系統。

先驗證 Profile 及所需場景／初始化資料再修改權威狀態；鎖定確認的本局 Profile 快照，不能載入期間被 UI 或 Asset 靜默替換。處理目前 startRunOnAwake 的自動初始化，避免 Scene 載入與新入口各開局一次。測試場景如需保留舊入口，必須明確區分，不得成為正式流程的第二個啟動者。

## 驗收條件

- [ ] 取消／未確認不載入 Gameplay、不生成半套 Run。
- [ ] 確認有效設定後確實從主選單 Scene 切至 SampleScene，新局使用該份 Profile 快照。
- [ ] 一次要求只建立一個 Run，連按、重複回呼與 Awake 不能重複套效果或進事件。
- [ ] 新局士氣 100/100、Stage 0，其他起始資料依目前合法配置初始化，不憑舊局殘留或舊示例重設成另一種平衡值。
- [ ] Asset 後續變動不靜默改寫已建立的新局快照；取消全域 +10% 的規則不被此流程重新加入。
- [ ] 既有開局事件、牌組、建築、探索初始化與合法流程順序維持。
- [ ] Scene 遺漏／載入失敗／初始化失敗時保持不可操作，給出失敗狀態並可回占位入口重試，不殘留部分可操作資料。

## 不在範圍與證據

不製作正式主選單 UI 或新增 Profile 平衡、設定種類、存檔。尚無新測試結果；需分別驗證初始化邏輯與實際 Scene 切換。
