# PB-P3-005：正式主選單 Scene UI 與 E3 流程接線

- 狀態：Backlog／未排程，尚未實作或驗收。
- 建立：2026-11-02，使用者要求將正式主畫面 UI 從 E3 拆出。
- 前置：PB-P0-014E-E3-001～004 的接口與跨場景閉環完成。
- 關係：PB-P3-001 是泛 UI 品質項；本項專責主選單，不重做 Gameplay HUD 或 E3 初始化／清理。
- 順序：[Story-Sequence](../Story-Sequence.md)。目前只確認 E3 在前；不自行指定它相對其他未排程項的順位。

## 範圍

在獨立的主選單 Scene 製作正式主畫面 UI，取代 E3 的白畫面／簡易控制。提供既有新遊戲入口、士氣 Profile 與已實作開局設定的選擇、開始／取消及錯誤或載入狀態。E3 是該 UI 呼叫的流程部件，也可透過獨立選擇畫面呈現；具體布局與畫面切分在本 Story 設計時確認。

## 驗收條件

- [ ] 主選單 Scene 與 SampleScene（遊戲內）明確分離，正式畫面替代占位而不建立第二套開局邏輯。
- [ ] Profile 展示名稱、三階實際效果及不可逆說明，不能混搭個別效果或誤把 Stage 理解成可指定崩潰階段。
- [ ] 開始、取消、返回與載入／錯誤狀態只透過 E3 接口操作；不由 UI 自行清空資源或呼叫各 System 套效果。
- [ ] 有效選擇才可開始，連按與場景切換時焦點／輸入隔離正確，初始化／轉場失敗可理解並可重試。
- [ ] 崩潰返回後主選單可正常選擇並新開局，沒有舊詳情、動畫、選項或鎖殘留。
- [ ] 正式排版在 1920×1080、1280×720 與灰階可讀，動態與可操作狀態不只靠顏色辨識；保留減少動態需求。
- [ ] 更新對應 UI API／接線及關係圖，證據區分邏輯定向測試、實體輸入與畫面驗收。

## 不在範圍

存檔／讀檔、成就、設定選單全集、終局選擇、新 Profile 內容平衡。這些沒有因主選單存在就自動成為需求。
