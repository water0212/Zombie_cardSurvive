## Scope

唯讀輪末預測、常駐士氣與金字塔、懸停／右鍵詳情、食物／資源／戰鬥／士氣分散預警、殭屍後果資訊、結束本輪危險確認及冪等 Editor 套用工具。

## Acceptance Criteria

- [x] E1-01：未就緒不顯示為 0；新局目前士氣、Stage、三層金字塔與 Profile 一致；詳情包含上限、永久損失、下一門檻、效果與不可逆說明。
- [x] E1-02：重複預測不改遊戲狀態、牌組、保留量、排程、階段或亂數；不揭露未抽卡／未知事件。
- [x] E1-03：相同已知輸入下預測與實際結算一致，涵蓋短缺封頂、臨時／保留食物、鼓舞付款與失敗原因、自然回落、永久上限限制、擊殺標記、反應窗口及階段效果時機。
- [x] E1-04：永久損傷時士氣區不顯示精確終值或傷害總量；各殭屍仍顯示已知後果；無永久損傷時標明「依目前已知狀態」。
- [x] E1-05：交易完成後更新分散預警；目前值與尚未結算的預測清楚區分；危險首次出現才短暫強調，解除後撤除。
- [x] E1-06：只有結束本輪的崩潰／跨階／永久損傷風險需要確認；多風險合併一框，預設返回；取消不變更資料，確認重新驗證資料。
- [x] E1-07：70／69、35／34 判斷正確，回復不恢復 Stage；現有 Failed／事件／探索鎖定無法繞過；關閉詳情或確認的輸入不穿透。
- [x] E1-08：1920×1080、1280×720 可讀且不遮擋；灰階能辨別；文字、圖示與減少動態效果符合核准方案。
- [x] E1-09：Editor 工具重複執行不重複建立物件，不重建場景，不覆蓋手動排版；建築／事件／探索小範圍回歸可用。
